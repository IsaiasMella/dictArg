# Proyecto Voice

Voice funciona como aplicación local Tauri + React. La transcripción usa Deepgram desde Rust y el formateo opcional usa Groq. Historial y diccionario se guardan en SQLite. No hay login, venta ni servidor propio.

Comandos: `npm run dev`, `npm run build`, `npm run check`.

No subir credenciales al repositorio. Mantener las migraciones SQLite acumulativas.
